# Clue-Less

## Installation

**Node.js 20 or newer** is required. `npm` is included with Node.

### Install Dependencies
```bash
cd clue-less
npm install
```

## Running the app

Start the server:
```bash
npm start
```

Then open **http://localhost:3000** in your browser. To test multiple players on one computer, open the page in several browser tabs or windows.


### Development mode

```bash
npm run dev
```

This restarts the server automatically whenever you save a file.


### Changing the port

The server uses port 3000 by default. To use a different port:

```bash
# macOS / Linux
PORT=4000 npm start

# Windows (PowerShell)
$env:PORT=4000; npm start
```
